# algoTrader@SoftMax — 자동매매 함께 만들기

파이썬으로 주식 자동매매 시스템을 처음부터 함께 만들어가는 강의 코드입니다.
유튜브 채널 **algoTrader@SoftMax** 에서 사용하는 코드를 정리합니다.

## 사용 환경

- Windows (크레온 API는 윈도우 전용)
- Python **32비트** (크레온 API는 32비트에서만 동작)
- 대신증권 크레온 (CreonPlus) 설치 및 시스템 트레이딩 신청 완료
- python.exe / pythonw.exe 관리자 권한 실행 설정

## 코드

| 파일 | 내용 |
|------|------|
| `creon_launcher.py` | 크레온 자동 접속 론처 (CreonPlus 실행 + 연결 확인) |
| `account_info.py` | 계좌 정보 조회 (평가금액·평가손익·예수금·보유종목) |

## 사용 방법

1. 필요한 라이브러리를 설치합니다.
   ```
   pip install pywinauto pywin32
   ```
2. `creon_launcher.py` 상단의 **본인 정보**(아이디·비밀번호·공인인증서 비밀번호)를
   따옴표 안에 본인의 실제 값으로 바꿉니다.
3. 관리자 권한 파이썬(또는 파이참)에서 `creon_launcher.py`를 실행해 접속합니다.
4. 접속된 상태에서 `account_info.py`를 실행하면 계좌 정보가 출력됩니다.

## 주의

- 이 저장소의 코드는 **크레온 API를 다루는 도구 코드**입니다. 매매 판단 전략(로직)은 포함되어 있지 않습니다.
